# WebStudio: Modal Interface

A WebStudio agency landing page from the GoIT HTML/CSS learning track.

## About the project

This version extends the WebStudio layout with a service-request modal interface. It brings together the page sections from earlier assignments and adds a separate stylesheet for the modal component.

## Highlights

- Responsive-style agency page structure
- Header, hero, features, team, portfolio, and footer
- Service-request modal markup and styling
- Dedicated CSS files for page sections and modal UI
- Reusable layout containers and interface styles

## Technologies

- HTML5
- CSS3
- Flexbox
- Modern Normalize
- Google Fonts

## Run locally

Clone the repository and open `index.html` in a browser. No build process is required.

## Learning focus

Composing a multi-section landing page, separating component styles, and designing a modal interface. This repository represents a course assignment rather than a production agency website.
